## 🚀 What I'm building

### Flow — SaaS, AI Agent & RAG
I work on the evolution of **Flow**, a multi-organization SaaS used by real clients to manage service operations.

My work includes:

- **Refactoring and evolving the product architecture and UX**
- Mapping legacy screens, navigation flows and business operations before the V2 redesign
- Structuring the project with **Spec-Driven Development**, using versioned specifications and business rules to reduce ambiguity and rework during implementation
- Building a **RAG-based AI agent** connected to the product knowledge base
- Structuring contextual chunks, metadata and versioned documentation for reliable retrieval
- Creating and maintaining **REST API integrations**
- Automating workflows through **WhatsApp / Meta API**
- Improving engineering reliability with **GitHub Actions, automated CI/CD and database migration workflows**
- Applying AI throughout the engineering process for requirement refinement, code analysis, architecture decisions, testing and documentation

During the modernization process, I also mapped the legacy system programmatically, reducing an initially noisy representation to a structured model with:

- **67 screens**
- **1,656 navigation relationships**
- **56 canonical operations**

The goal is not simply to "use AI", but to create a development environment where **requirements, architecture, code and product knowledge are structured so AI can operate with better context and fewer assumptions**.

## 📊 Applied Data Science & Machine Learning Research

### Revenue Forecasting — UNICAMP × PGE-SP
I'm an **undergraduate researcher at UNICAMP**, working with the **São Paulo State Attorney General's Office (PGE-SP)** on a project focused on forecasting public revenue.

The project involves a complete analytical and modeling pipeline:

- Data ingestion through APIs
- Schema profiling and data validation
- Exploratory Data Analysis
- Time-series feature engineering
- Lag variables, rolling statistics and seasonality
- Macroeconomic explanatory variables
- Statistical forecasting models
- Machine Learning models and ensembles
- Temporal validation with **walk-forward strategies**
- **Anti-leakage** methodology
- Model comparison and error analysis
- Explainability and residual analysis
- Continuous model monitoring concepts

### Models & techniques
`ARIMA` · `ARIMAX` · `SARIMA` · `XGBoost` · `Prophet` · `Linear Regression` · `Random Forest` · `Logistic Regression`

### Evaluation
`MAE` · `RMSE` · `MAPE` · `Accuracy` · `Precision` · `Recall` · `F1-score` · `Cross-validation`

The research connects **statistics, Machine Learning and real-world decision making**, with a strong focus on methodological correctness and avoiding data leakage.
